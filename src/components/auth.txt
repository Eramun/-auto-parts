Монолит - backend и frontend яыляются частями одного цельного приложения ( за формирование frontend части отвечает backend часть).

Распределенное - backend и frontend явлются отдельными приложениями взаимодейсвтие между которыми реализовано зачастую через протокол HTTP.

Авторизация - процесс получения прав на выполнение определенных действий в приложении(зачастую для получения прав требуется предоставить авторизационные данные,
например комбинация логина и пароля). В распределенных приложениях авторизация основана на токенах доступа(access token ). Токеном называется строка
представляющая собой криптографический шифр сосотящий из различных символов (в основном буквы и цифры). Обычно в токене доступа фиксируется
сторона запрасившая токен, права на выполнение действий в системе, срок службы(время на которое токен будет актуален для использования).

Последовательность действий для авторизации по токену доступа:
1)Клиент отправляет запрос к серверу на получение токена доступа по авторизационным данным.
2) Сервер проверяет авторизационные данные и если они корректны, возвращает токен доступа.
3) Клиент сохраняет полученный от сервера токен доступа в браузерном хранилище(localStorage либо sessionStorage) либо другим образом.
4) Клиент передает сохраненный токен доступа в каждом последующем запросе к серверу для авторизации.

Pinia - библиотека от разработчиков фреймворка Vue предназначенное для работы с глобальным состоянием при помощи механизма хранилищ (store).
Под глобальным состоянием подразумевается возможность использования разных общих данных и функций для взаимодействия с ними в разных компонентах.Такие библиотеки
как Pinia удобно использовать для чего-то глобального в приложении (например состояния авторизации, либо использемый язык , тема оформления и так далее).
