SPA(single page application) - одностраничное  приложение создаваемое при помощи библиотек таких как Vue, React, Angular.
Одностраничное приложение называется таковым за счет единственного HTML файла находящегося в нем (этот же файл является точкой входа в приложение)
Структура HTML файла в SPA приложении формируется за счет JS кода (компонентов). В SPA приложении может быть несколько страниц
которые будут отрисовываться условно в зависимости от адреса к которому идет обращение из браузера(реализовать такое поведение позволяет библиотека
называемая маршрутизатором). В Angular встроен по умолчанию модуль маршрутизации и не требует отдельной установки, в React и Vue маршрутизация
не встроена в саму библиотеку и требует установки отдельной библиотеки.Библиотека маршрутизатор для Vue называется Vue Router и
разрабатывается непосредственно


При написании любого проекта важно грамотное формирование его структуры чтобы исключить в дальнейшем неочивидность кода, рекомендуется
разделять компоненты приложения на следующие группы.
1)'pages' - компоненты описывающие отдельно вщятую страницу в приложении (главная, корзина, и так далее)
2)'components' - компоненты используемые на отдельно взятой страницу единственный описывающие часть интрефейса которая не будет использоваться
на других страницах
3) 'ui' - компоненты описывающие зачастую интерактивную часть интерфейса которая может быть переисользована на различных страницах
(выпадающий список, текстовое поле, кнопка, постраничная навигация и так далее).
